# Portfolio Website — Complete Light & Dark Mode Color System

Design the portfolio website with a carefully designed **dual-theme color system**.

The website must support:

1. **Light Mode — Fresh Ocean**
2. **Dark Mode — Warm Ember**

The two themes should feel like the same professional developer brand, but each should have its own atmosphere.

Do NOT simply invert the colors between light and dark mode.

Light Mode should feel:

* Fresh
* Calm
* Clean
* Bright
* Modern
* Professional
* Refreshing
* Spacious

Dark Mode should feel:

* Premium
* Warm
* Powerful
* Modern
* Energetic
* Sophisticated
* Slightly futuristic
* Visually rich without becoming flashy

The color system must be consistent throughout the entire website.

---

# 1. LIGHT MODE — "FRESH OCEAN"

The light theme should use a combination of:

* Very light blue
* White
* Ocean blue
* Sky blue
* Teal/mint
* Deep slate

The website should feel similar to a clean ocean/sky atmosphere.

## Primary Background

Use:

`#F0F9FF`

This should be the primary page background.

Do NOT use pure white as the entire page background.

The very subtle blue tint should make the interface feel cooler and more refreshing.

---

## Main Surface

Use:

`#FFFFFF`

Use pure white for:

* Cards
* Navigation
* Important content containers
* Modals
* Project cards
* Skill cards
* Contact forms

White surfaces should sit naturally on top of the light-blue page background.

---

## Secondary Background

Use:

`#E0F2FE`

Use this for:

* Alternate sections
* Soft highlighted areas
* About sections
* Skill backgrounds
* Large decorative areas
* Subtle hero backgrounds

Do not overuse it.

# 31. THEME TRANSITION

When switching themes, smoothly animate:

* Background
* Text
* Cards
* Borders
* Buttons
* Icons
* Shadows
* Glows

Do NOT animate layout positions.

The content should stay exactly where it is.

Only the visual theme should transition.

---

# 32. IMPORTANT COLOR RULE

Do NOT mix the two theme identities excessively.

LIGHT MODE:

Primary identity:

BLUE + SKY BLUE + MINT

Dark Mode:

ORANGE + AMBER + CORAL

For example:

Light:

`#0EA5E9`

Dark:

`#FF6B35`

The same component should automatically use the appropriate theme variable.

---

# 33. CSS VARIABLES

Create a centralized theme system.

Example structure:

```css
:root {
  --background: #F0F9FF;
  --surface: #FFFFFF;
  --surface-secondary: #E0F2FE;

  --primary: #0EA5E9;
  --primary-hover: #0284C7;
  --secondary: #38BDF8;
  --accent: #2DD4BF;

  --heading: #0F172A;
  --text: #475569;
  --text-muted: #64748B;

  --border: #BAE6FD;
}

.dark {
  --background: #0C0A09;
  --surface: #211713;
  --surface-secondary: #17110E;

  --primary: #FF6B35;
  --primary-hover: #F97316;
  --secondary: #F59E0B;
  --accent: #EF4444;

  --heading: #FFF7ED;
  --text: #D6C7BC;
  --text-muted: #A8998E;

  --border: #3A2922;
}
```

Do not hardcode colors throughout individual components.

All components should consume the centralized theme variables.

---

# 34. OVERALL DESIGN RULES

Follow these rules strictly:

1. Do not use pure black backgrounds.
2. Do not use excessive gradients.
3. Do not make every element colorful.
4. Do not use neon effects everywhere.
5. Do not use heavy shadows.
6. Do not use too many different accent colors.
7. Maintain strong text contrast.
8. Keep large areas visually calm.
9. Use accent colors mainly to guide attention.
10. Keep the design professional enough for a senior/lead developer portfolio.

The website should feel like a premium SaaS/developer product rather than a gaming website.

---

# 35. COLOR HIERARCHY

LIGHT MODE:

60% — `#F0F9FF` / white backgrounds

25% — dark slate typography

10% — ocean/sky blue

5% — mint and other accents

DARK MODE:

65% — dark warm backgrounds

25% — warm-white typography

8% — orange/amber

2% — coral/gold special accents

This keeps the design visually balanced.

---

# 36. FINAL VISUAL PERSONALITY

LIGHT MODE should communicate:

"Fresh • Clean • Calm • Intelligent • Modern"

Think:

🌊 Ocean
☁️ Sky
💧 Fresh Water
☀️ Morning Light

DARK MODE should communicate:

"Premium • Warm • Confident • Powerful • Modern"

Think:

🔥 Ember
🌅 Sunset
🟠 Warm Light
🌋 Subtle Fire

Both themes should clearly belong to the same developer portfolio brand.

The final result should look **minimal, premium, modern, spacious, highly polished, and professional**, with excellent typography and subtle animations.

Avoid generic "developer portfolio" aesthetics such as excessive purple gradients, glowing neon borders, glassmorphism everywhere, or overly futuristic UI.

The color system should enhance the content rather than distract from it.
